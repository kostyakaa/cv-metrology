# cv-metrology
CV интерфейс для измерительной микроскопии

## Рабочий режим

```powershell
python scripts/scan_plane.py --camera-name "UC60 Video" --width 1920 --height 1080 --calib calib/calib_cam0_1920x1080_pinhole.json --port COM4
```

1. Наведите камеру на угловую метку ID0–3. В окне камеры нажмите `c` для подключения
   и `k` для проверки осей и привязки. После подключения ручной ход работает через
   `WASD`, шаг выбирается клавишами `1`, `2`, `3` (0,1 / 1 / 10 мм).
2. Нажмите `r` для обхода четырёх меток и сохранения рамки. Если плоскость
   ещё не измерена, геометрия изменилась или программа просит обновить плоскость,
   нажмите `t`. Скрипт измерит высоту у каждой угловой метки.
3. Нажмите `p` для съёмки всего поля. В мозаике колёсико меняет масштаб.
   Левый клик выбирает точку, `g` подводит камеру к её XY. После остановки скрипт
   сравнивает кадр с окрестностью точки на мозаике и выводит остаток по X/Y.
   При однозначном совпадении допускаются две доводки до 1,2 мм каждая.
   Если в центре нет текстуры или совпадения расходятся, скрипт оставляет результат
   основного хода. `q` возвращает в окно камеры.
   Клавиша `v` снова открывает мозаику.
4. Для карты высот подведите камеру к нужному участку с помощью мозаики или `WASD`.
   Закройте мозаику через `q` и нажмите `b` в окне камеры. По умолчанию локальный
   скан снимет сетку 5×5 и откроет карту высот. Клик измеряет точку, `g`
   наводит камеру на надёжно измеренную точку. Исходники и результат сохраняются в `scans`.

## Короткая аппаратная диагностика

`--trial` предназначен для проверки визуальной одометрии возле одной метки.
Для обхода, ручного хода и съёмки поля используйте рабочий запуск выше.

Из корня проекта запустите `python scripts/scan_plane.py --preflight --port COM4`.
Команда сверяет калибровку, раскладку и плоскость, перечисляет устройства и завершается.
При другом номере порта подставьте номер USB-контроллера из диспетчера устройств.
Для этой установки сохранены UC60 Video, 1920×1080, ручной фокус 185 и
`$3=1`, `$100=800`, `$101=800`.

1. Поставьте камеру над центром одной видимой угловой метки ID0–3. Сохранённая раскладка
   применима, пока метки, высота камеры и крепление остались на своих местах.
   Закрепите рядом матовую контрастную текстуру на высоте метки для оптического потока.
   Оставьте шпиндель выключенным. Проверьте зазор для каретки, стола и кабеля:
   пробные ходы `k` идут также к положительным осям, даже если это наружу от метки.
   Выберите угол с запасом хода. Держите доступным физический останов.
2. Запустите `python scripts/scan_plane.py --trial --port COM4`.
   Проверьте изображение, ID метки и показания фокуса драйвера. Нажмите `c`,
   затем `k`. При пробе осей сверьте реальное направление относительно стола.
   Клавиша Esc в окне отменяет jog. При потере связи используйте физический останов.
3. Нажмите `p` и сверьте выведенные смещения от старта с доступным ходом.
   Маршрут проходит квадрат со стороной 6 мм к внутренней части поля и возвращается
   на старт. Записываются пять остановок, кадры движения используются для одометрии.
   Подача ограничена 120 мм/мин, любая цель должна лежать в пределах ±8 командных мм
   по каждой оси от подключения. Без концевиков эти пределы отсчитываются по GRBL.
   При потере стартовой метки или расхождении её перемещения с GRBL свыше 0,5 мм
   скрипт завершает маршрут на текущей остановке. Причина попадает в `mosaic.json`.
4. Откройте отчёт командой `python scripts/mosaic_report.py mosaics/<сеанс>/fused`.
   Для незавершённой пробы укажите сам каталог сеанса. Для рабочего первого прогона
   ожидаются `complete=True`, пять наблюдений метки, четыре проверенных участка движения
   с промежуточными статусами GRBL и видимый возврат камеры на ту же метку. При `lost`
   посмотрите, где пропала текстура или появился блик. При отсутствии промежуточных
   статусов попробуйте меньшую подачу, например `--feed 60`.

Порог 0,5 мм ловит грубое расхождение. Для проверки цели 0,1 мм закрепите на рабочей
высоте независимую измеренную сетку и оставьте контрольные точки вне подгонки.
После полного скана выберите несколько точек у углов и в центре. Повторите наведение
с разных сторон и измерьте фактическое отклонение от каждой точки до доводки.
Сохраните ошибки X/Y, их длину и наибольшую ошибку.

## Сборка скана плоскости

После съёмки клавишей `p` в `scripts/scan_plane.py` исходные кадры и координаты
GRBL остаются в каталоге сеанса. В подкаталоге `fused` появляется мозаика,
уточнённая по оптическим смещениям вдоль и поперёк строк и по меткам.
Освещение смешивается в перекрытиях, мелкие детали берутся из одного исходника.
Сохранённый скан можно пересобрать без подключения оборудования.

```powershell
python scripts/rebuild_mosaic.py mosaics/<сеанс>
python scripts/mosaic_report.py mosaics/<сеанс>/fused
python scripts/scan_plane.py --view mosaics/<сеанс>/fused
```

Для повторной сборки укажите новую папку через `--out`. Для сравнения доступен
режим `--grbl-only`. При клике по уточнённой мозаике окно показывает XY на
плоскости и координаты команды относительно домашней метки.

В `fused/mosaic.json` поле `records[].position` содержит показание GRBL при
съёмке, а `fused_position` — оценку после совмещения. В разделе `registration`
поле `optical_trajectory` показывает последовательные визуальные шаги.
Поле `optical_positions` восстанавливает относительный XY также по поперечным
связям. Сравнивать координаты можно у кадров с одинаковым `origin_frame`.
Масштаб задаёт калибровка камеры и плоскости. При новом сканировании
`motion_from_previous` также хранит оптические шаги на ходу, время получения
кадров и статусы GRBL. Время получения отличается от времени экспозиции.

В отчёте RMS и p95 считаются по отложенным парам кадров и наблюдениям меток
из того же скана. Для оценки абсолютной точности наведения нужна отдельная
проверка на известных точках поля.
